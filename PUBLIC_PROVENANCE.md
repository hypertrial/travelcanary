# Public release provenance

The initial public application tree was imported from Git-tracked content at `hypertrial/travelcanary-risk` commit `e780697f957de8a072b70c4fe771345bd1315b8d`. The import did not read untracked or ignored working-directory content.

The public import includes current lawful application code, Vercel adapters, catalogs, mappings, generated artifacts, minimized test fixtures, source reviews, tests, documentation, and assets.

The following private or machine-specific paths were deliberately excluded:

- `.agents/`, `.pad/`, `.pad.toml`, `AGENTS.md`, `CLAUDE.md`, and `PROJECT_AGENT.md` from the private repository
- environment files other than the redacted `.env.example`
- credentials, ingestion databases and state, production snapshots, backups, raw upstream captures, build output, caches, test reports, and local operational records

The public repository supplies its own contributor-facing `AGENTS.md`. First-party code is offered under MIT; third-party material remains under the terms recorded in `THIRD_PARTY_NOTICES.md` and `data/source-inventory.json`.
