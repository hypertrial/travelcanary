New modeled conditions: weather, modeled AQ and marine. New independent observations: reviewed airport METAR, seven exact Rijkswaterstaat NAP water-level mappings, and seventeen exact ARSO gauge mappings across all seven Slovenian destinations. Infrastructure context adds Digitraffic, Krisinformation, NDW, Autobahn, and PSE. None of these records can become an alert, marker, delayed hazard, or monitoring claim. Fallback improvement: exact Irish counties; no new weather provider. **No new monitoring-completeness claim.**

Review at least every 90 days or immediately on API, license, footprint, schema, quality-code or product-model changes. Monetization requires disabling noncommercial paths and completing a fresh license review. The dormant entries above must not be described as shipped data sources.

The 2026-09-08 OPW bulk gate returned 731,596 bytes and six current mapped primary readings. The official error listing includes code 0 and excludes 99; station pages display these 99 readings. This supports provisional context only, not a general quality-code legend. Unknown/missing/error codes are rejected. No Malin/Poolbeg conversion is performed.

The September 8 NDW recovery supports the current DATEX3 single `messageContainer/payload` and existing DATEX2 envelope. V3 requires version 3, SituationPublication, publication age under two hours, and real/unrestricted headers. Explicit maintenance vehicles, ambiguous described `other` causes and unsupported validity schedules are excluded or fail safely; this is conservative context, not complete road coverage.
