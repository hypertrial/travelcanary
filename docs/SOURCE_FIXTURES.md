# Source Fixture Guide

## Local conditions V2 / private state V12

`tests/fixtures/conditions` contains real minimized 2026-08-31 Open-Meteo weather/AQ, MET Norway forecast, AWC island observations, IPMA station/seismic responses, Rijkswaterstaat water levels, and an ARSO schema-1.5 hydrology response. Open-Meteo forecast issue time remains null: processing metadata is not a model issue time. MET Norway retains its explicit issue time. IPMA fixtures preserve UTC timestamps, `-99` missing values, empty/sentinel seismic update fields, magnitude, and coordinates while omitting descriptive prose. The ARSO fixture preserves fixed-CET time, official station identity/coordinates, water body, gauge-zero datum, level, flow, temperature, and first reference levels; those crossings remain contextual and are not warning fixtures. Tests enforce hourly alignment, units, nulls, timestamps and age. `smoke:conditions` separately gates Galway's committed offshore point, the full 11-destination Swiss weather batch, and representative Autobahn targets against current bounded responses; transient live failures do not weaken fixtures or parser rules. `traffic-datex.xml` minimizes official situation GUID50469906, removing prose/contact/location-reference fields; intersection tests use explicitly synthetic destination geometry. The live smoke validates the full official geometry join.

Infrastructure parser fixtures are deliberately synthetic and rights-safe. They preserve only contract fields needed to prove identifiers, official update/validity time, status, exact geometry or reviewed area, and structured event class for Krisinformation, NDW DATEX II, Autobahn, EAC, Enemalta, and PSE. Tests reject tests, resolved notices, routine works, lane restrictions, unknown types, stale/future rows, malformed geometry, source-shape drift, and raw publisher prose. EAC remains runtime-gated because its five official pages failed the bounded live gate; the fixture proves parser behavior, not Production access.

NDW regressions distinguish valid empty SituationPublications from envelope or record drift, and verify that failed parsing preserves unexpired incidents. Cached planned closures change their displayed timing when their scheduled start passes without rewriting the source status or check time. IPMA proximity tests include an earthquake near the interior of a polygon edge, not only near its vertices.

`data/review-inputs/airports.json` and `gvp-holocene.json` retain minimized reviewed inputs and original checksums. `data/arso-hydro-mapping.json` records exact reviewed Slovenian station/water-body pairs, destination intersections, source contracts, and reuse citation. Regenerate derived eligibility with `npm run conditions:mappings` and volcanic applicability with `npm run applicability:generate -- --input data/review-inputs/gvp-holocene.json --reviewed-at 2026-08-31`. `conditions:check` rejects mapping drift. Do not replace reviewed stations or airports with a runtime nearest-point search.

Run `npm run conditions:demo` after the alert demo generator. These files explicitly repeat demonstration values across destinations and must never be used as production evidence. Conditions have exact country ID sets, bounded attribution, expiry and transport-specific replacement. See [source review](KEYLESS_SOURCE_REVIEW.md) for incomplete activation gates; do not invent fixtures to claim an undocumented production contract passed.

CI never calls live hazard sources. Adapter tests use small captured or synthetic fixtures that preserve the source contract without republishing unnecessary upstream content.

## Refresh procedure

Regression coverage includes severity-first national caps after same-ID reconciliation, age-based national transport delays, independent IMGW measurement/bulletin clearing, mixed-validity EFFIS raster retention, and permanent AQI counts across temporary failures. Reviewed AQI exclusions remain permanent gaps rather than late checks. Repeated partial EFFIS rasters delay only unavailable destinations, leave permanent fire-danger checks unchanged, and never delay global health; previously successful scopes become delayed when the whole source misses its cadence. An unrelated delayed hazard must not relabel a current scoped provider as late. FMI fixtures use the official profile `eventCode`/`valueName`; fire weather maps to fire danger, not an active wildfire. GDELT charges interrupted bodies to its shared fetch budget and stops after an oversized combined response; a disabled context switch remains disabled rather than appearing late.

The avalanche mapping generator requires the existing reviewed V2 artifact and complete current EAWS geometry. It validates intersections while preserving feed enablement, attribution, review dates, destination scope, and region-prefix matching (bulletins can use parent regions rather than micro-region IDs). Missing intersections fail before writing. Its regression test runs the generated artifact through the real coverage generator in temporary storage. New destinations, prefixes, or feed decisions require explicit review; geometry regeneration is not a source-readiness review.

1. Recheck the source license and endpoint documentation.
2. Run `npm run smoke:sources -- SOURCE_ID` to confirm the live parser without writing state. Its JSON includes provider mode and health scope, bounded partition problems, unavailable counts, duration, requests, retries, bytes, outcome codes, and overflow codes.
3. Capture the smallest response fragment needed for the behavior under test.
4. Remove unrelated descriptions, personal data, binary products, and publisher-owned text.
5. Preserve identifiers, structural fields, timing, severity, geometry, cancellation, and attribution fields.
6. Add boundary, malformed, empty, delayed, and cancellation variants.
7. Run unit tests, data validation, and build.

For MeteoAlarm, fixtures must preserve `valueName`, geocode, `areaDesc`, message type, lifecycle references, and structured emergency instructions when relevant. Include representative `EMMA_ID`, current NUTS, legacy NUTS, mismatched-code/area-label, ISO country codes that must not match as country-wide, explicitly country-wide cases, alert/update/cancellation chains, and `Minor` or `Unknown` advisories that are healthy but publish no risk event. Adapter tests must also cover all 28 official country Atom URLs, one-country failure, recovery, successful-empty replacement, source update times more than two hours stale or more than five minutes ahead, retained evidence after a stale refresh, Atom concurrency 10, global CAP concurrency 4, CAP URL deduplication, feeds between 2 and 4 MiB, up to 2,000 bounded Atom records, and lifecycle records that need no supplement when Atom already carries references or the update has expired. Never substitute the retired RSS endpoints. A parser event count alone does not validate catalog matching; the fixture must assert at least one intended location match and one nearby non-match.

For EEA AQI, preserve only `locationId`, official category value, raster ID, and raster `StdTime`. Cover values 1–6, multiple sample points selecting the worst category, missing/stale points, 250-point batching, byte caps, and exclusion of the three Azores and two Canary destinations from requests and freshness health. Never replace official categories with pollutant calculations. Dormant Canary WMS parser fixtures preserve `level` and `update_at` from `ESTACIONES` feature info and prove fail-closed parsing; they do not establish runtime activation or coverage.

For EFFIS/FIRMS active fire, use a minimal candidate GeoTIFF, feature-info record, current-slice WMS confirmation, bounded WFS 1.1 GML perimeter response, and the minimum FIRMS rows needed to prove time, coordinates, sensor, and confidence. Cover full-raster connected components (including a late-row component nearer the catalog), deterministic 50-component overflow, current/stale/malformed perimeters, paired detections no older than 12 hours, the 25 km boundary, hotspot fallback, and the 4 MB perimeter budget. Missing FIRMS credentials must still make the keyless EFFIS request. Never retain or print a map key.

For USGS, preserve candidate order, event lifecycle, detail links, preferred ShakeMap product metadata, grid field definitions, and intensity rows. Exercise multiple qualifying candidates with an in-flight limit of three, out-of-order completion, missing detail/grid fallback, off-allowlist detail and grid URLs, deletion, expiry, summaries generated more than 30 minutes ago or more than five minutes ahead, and retained earthquake evidence after a stale refresh.

Implemented paths include GDELT corroboration (currently reliability-gated in Production), FMI/Met Éireann/IPMA/AEMET/DHMZ direct and optional IFRC MeteoAlarm recovery, GloFAS-directed GFM, verified EFFIS perimeters, and ten active national partitions. Fixtures must prove stable IDs, time, geometry, thresholds, caps, deterministic overflow, healthy-empty clearing, rights-safe output, and transport-scoped replacement. Credential- and evidence-gated systems make no request.

Recovery regressions must exercise state merging after repeated successful FI/IE or IFRC recovery: the recovered partition stays partial with no accumulated failures while the failed primary transport remains visible. Temporary provider health must not change permanent monitoring counts. CHMI healthy-empty bulletins and successful station readings clear only their own earlier evidence even when the other subtransport fails. CEMS detail-level closures remove their activation during an unrelated partial failure; malformed or future-dated closures retain evidence. GDELT PointData HTML links without article publication timestamps are discarded, not assigned retrieval-derived publication times. Keep GDELT gated until both reliability and trustworthy article-time delivery are verified; repeated retrieval of dated articles must not extend their publication-based expiry.

Failed USGS impact-product requests are partial: preliminary fallback remains available, but merging retains prior unexpired shaking evidence for the failed event IDs. Successful later products may downgrade or clear that evidence. Mixed CEMS AOIs retain unresolved areas while replacing successfully parsed areas, including those that no longer affect a destination. Malformed EAWS JSON envelopes cannot clear bulletins, and missing sibling EEA samples cannot establish a fully checked destination or lower its retained category for that time slice. LU catch-up tests persist successfully processed alerts before advancing the transport watermark and apply cancellations even during a partial run.

Italian fixtures preserve the complete Topology zone set, exact `Nome zona` identifiers, the four structured risk fields, and green/yellow/orange/red classes. Regenerate `data/italy-flood-zone-mapping.json` offline with `npm run mapping:it-flood -- OFFICIAL_TOPOLOGY.json`; tests require reproducible intersections, healthy green, unknown-class failure, and partial handling when a reviewed zone disappears. FMI fixtures preserve the RSS-to-CAP link, Actual/Public scope, lifecycle references, exact event codes, structured severity, validity, and polygons. Unknown non-green classes fail closed and `Last-Modified` supplies source freshness. Unknown Irish counties fail closed. All direct fallbacks must prove zero calls for a healthy MeteoAlarm partition, and a later IFRC recovery must preserve the failed direct transport's health.

IMGW fixtures preserve station ID, water level, warning/alarm thresholds, the API's timezone-less UTC measurement time, Warsaw civil time in text bulletins, warning directory entries, bulletin degree 1–3, validity, and area tokens. Cover exact boundaries, stale and future measurements, malformed rows, healthy empty, station/bulletin split failure, out-of-scope ungraded hydrological-drought notices and cancellations, a fail-closed 32-file completeness limit, and the 3 MB run budget. A destination with one current reviewed station remains current when a sibling station is stale; it becomes unavailable only when none of its reviewed stations is usable. The 2026-08-30 review found no stable documented exact warning-area geometry contract, so token matching remains partial and must not be presented as nationwide complete coverage. Prove the fallback is called only after failed country fetch/parse, remains `partial`, preserves originating URLs and CAP lifecycle, and is not called for healthy primary feeds.

For GDACS, fixtures must include instantaneous earthquakes where `fromdate` equals `todate`, known out-of-scope drought and volcano records that are ignored without degrading health, and an unknown event type that fails closed as a feed-contract change.

Krisinformation fixtures preserve the CAP identifier, publication/update times, `IsTest`, and official Polygon/MultiPolygon area. Production VMAs are always `ELEVATED`, `HIGH` confidence; text is never used to infer severity. Test VMAs must be rejected, and a present production VMA refreshes a rolling 30-minute expiry.

FR-Alert fixtures preserve the archive's Drupal settings identifiers, `Actual` status, `Last-Modified` fast path, export JSON timezone, structured severity/category, expiry, CAP-order `lat,lon` polygons, and CAP-standard circle radii in kilometres. No representative non-test FR-Alert or CAP-LU fixture currently proves a complete wildfire-warning code; generic `Fire`/`Incendie` categories remain ignored and satellite detections remain context-only.

The volcanic-applicability artifact is regenerated offline with `npm run applicability:generate -- --input SOURCE_GEOJSON --reviewed-at YYYY-MM-DD`. The input must be the current Smithsonian GVP Holocene WFS export. Tests cover the 200 km boundary, polygon/radius geometry, explicit overrides, distant cities, active-event override, known volcanic destinations, source digest, citations, and deterministic output. Runtime ingestion must make no GVP request.

AT-Alert fixtures preserve the official same-origin list RPC contract: `consolidation_identifier`, production `AlertLevel1`–`AlertLevel4`, title, start/end, and polygon or GeoJSON geometry in lon,lat order. A pair is swapped only when one ordinate is unambiguously a longitude (`abs > 90`). Test, exercise, monthly-test, and Amber records must be rejected. Missing geometry, an unsupported level, or a `totalCount` or page above 100 fails closed, publishes no events, and marks Austrian destinations unavailable. An empty official list is a healthy clear. AT-Alert publishes only `civil-emergency`; headlines are never used to invent security, industrial, or nuclear categories.

LHP fixtures preserve GeoJSON area geometry, CAP severity, documented `lhpClass`, update/onset/expiry, cancellation, source attribution, and mixed non-area reference features. Mixed-validity refreshes must retain unrelated unexpired warnings while applying explicit cancellation, class-1 all-clear, and expiry records by stable ID. A valid timestamped downgrade to `PREALERTA` clears that plan's prior evidence even when another record is malformed; impossible, ambiguous, malformed, or future-dated downgrades cannot clear retained evidence.

Vigicrues fixtures preserve the river-section code, official color, item time, and empty-feed structure. FOEN fixtures preserve the exact RGB palette and exercise a recognized neutral image, each severity boundary, the 90-minute rolling expiry, and an unrecognized-palette failure. SLF and Avalanche.report fixtures are compact extracts of CC BY 4.0 historical bulletins. Avalanche.report matching uses the committed CC0 EAWS micro-region intersections and must not add a destination based on its name alone.

EONET fixtures cover current wildfire/volcano points and polygons, 25/50 km boundaries, 72-hour freshness, malformed geometry, and the stale Kansas regression record. EDO fixtures are generated one-band TIFFs covering the exact 1,824×1,200 EPSG:4326 grid, class 3 only, stale product dates, changed dimensions, invalid class values, and 25-day expiry. FCDO fixtures cover whole-country avoid-all/essential statuses, ignored partial-country statuses, replacement, two-hour expiry, and partial country-page failure.

GFM grid fixtures keep aligned extent, likelihood, and advisory cells. GloFAS fixtures use the official `sumAL41EGE` days-1–3 summary and prove that target selection alone creates no event. Tests cover merged/deduplicated 12-target overflow, four-cell connectivity, likelihood 70, advisory zero, the 9 MB budget, and disabled gates making no request. CI never contacts the live WMS.

The [warning expansion fixtures](../tests/fixtures/warning-expansion/README.md) contain the real complete AEMET CAP archive, multilingual DHMZ today/tomorrow CAP, and all four LVĢMC tables. Provenance and SHA-256s are recorded alongside explicit synthetic lifecycle/overflow variants in the tests.
